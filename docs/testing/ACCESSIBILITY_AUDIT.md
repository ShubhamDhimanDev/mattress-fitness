# Accessibility audit groundwork (P7-05 preparation)

Requirement: NFR-003 (proposed WCAG 2.2 level AA, **pending client approval**, Q-012; AA is the working standard). Procedure: skill `accessibility-review`. Run on 2026-10-16 by the QA engineer.

**Everything here is local mock-store evidence.** It ran on the Hydrogen dev server (port 5300, `.env.delivery`: `bedding.mock.shop` plus the preview fixtures for brands, stores, quiz and compare), in desktop Chromium (1280 x 800) and mobile Chromium (set to 360 x 800). It is not evidence about the client's store, real content, the final brand colours, a real browser matrix, assistive technology or a real device. It does not show that the site conforms to WCAG; it shows what automation can see today and lists what a person still has to check. The Accessibility page text (REQ-CNT-001) must not claim more than this.

## Method

| Part               | How                                                                                                                                                                                                                                                                                                                                                               | Spec                                                                              |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Automated          | axe-core 4.14.0 through `@axe-core/playwright` 4.13.0, tags `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa` (supported by the installed axe) plus `best-practice`. Serious or critical violations fail the test; moderate, minor and best-practice results are recorded only                                                                               | `tests/e2e/a11y-audit.spec.ts`, helpers in `tests/e2e/helpers/a11y.ts` (additive) |
| Keyboard           | Tab walk of the whole page: first stop, every stop has a painted outline or ring, no stop is covered by another element, the order is header then main then footer, focus leaves the page again (no trap). Overlays, steppers, combobox, size selector, compare region and the quiz by key press                                                                  | same                                                                              |
| Reflow and spacing | 320 x 256 CSS px viewport (400 percent of 1280 x 1024; layout depends on CSS px, not on device pixels): no page-level horizontal scroll and no visible text or control beyond the edge outside a scroll container (WCAG 1.4.10). WCAG 1.4.12 spacing override (line height 1.5, letter 0.12em, word 0.16em, paragraph 2em): no clipped text, no horizontal scroll | same                                                                              |
| Motion, colour     | `prefers-reduced-motion: reduce`: no running animation longer than 100 ms or infinite (`document.getAnimations()`), polled for 5 s. `forced-colors: active`: focus drawn by an outline, dialogs have a border or outline                                                                                                                                          | same                                                                              |
| Counts             | `E2E_PORT=5300 npx playwright test tests/e2e/a11y-audit.spec.ts --project=<project>`                                                                                                                                                                                                                                                                              |                                                                                   |

Known limits of the method: axe finds roughly a third of WCAG problems; the focus-indicator check proves a painted outline or ring exists, not that its colour contrast is 3:1; "not obscured" is tested at the centre of the focused element only; the 400 percent test is a viewport equivalent, not a zoomed browser.

The P7-05 verdict cannot be given from this: the manual items above, the final palette and the development store are all outstanding.
