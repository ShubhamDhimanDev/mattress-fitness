Task P2-09. Owner: `ui-ux-designer`. Rule: [ui-implementation](../../.claude/rules/ui-implementation.md) ("record any intentional deviation"); process: [FIGMA_WORKFLOW](FIGMA_WORKFLOW.md) step 9.

## What this log compares

There is no approved design to deviate from: the SOW excludes static mockups (EXC-09) and no Figma file has been supplied (Q-004). The reference is therefore the structure notes in [REFERENCE_PATTERNS](REFERENCE_PATTERNS.md) (the owner's instruction is that the site should look and function like the reference site, in the client's own brand), and the built result is the code in `storefront/app` and the e2e specs that describe it. The tokens are in [BRAND_TOKENS](BRAND_TOKENS.md).

This log was written from those documents and the code on 2026-10-16. **No staging review has taken place and no screenshot has been shown to the client**, so every entry below is **pending client approval**. Each cites where the difference can be seen; entries copied from the reference notes without re-inspecting the page are marked "from the notes". Nothing is listed that was not observed in the code, the specs or the notes.

Statuses: **Pending client approval** (decision needed), **Waiting for content** (closes when the client supplies it), **Accessibility rule** (intentional, proposed as permanent). An approved or fixed entry keeps its row with the date and approver.

## Not deviations (checked against the notes)

- The header carries a delivery ZIP entry, a my-store link, a search field, account and cart on every page; below 1024 px the navigation moves behind a Menu button and opens as a drawer (`shell.spec.ts`).
- Desktop navigation groups follow the SOW list; a menu opens on hover or with Enter, Space or the arrow keys.
- The shared `Button` has a pill shape for navigation-level calls to action and a 4 px radius for choices; buttons are uppercase and bold (`Button.tsx`).
- Collection pages use a "Load more" button (notes, checked 2026-10-15).
