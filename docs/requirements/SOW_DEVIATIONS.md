## How approvals are recorded

1. The project owner sends the client pack ([CLIENT_QUESTION_PACK](CLIENT_QUESTION_PACK.md)).
2. The client's written reply (email is enough) is stored with the date in `progress/DECISIONS.md`, one line per SD row, with the client name. **"Let's talk" is not an approval.**
3. A row moves to `ACCEPTED`, `DECLINED` (the SOW item is then dropped or re-quoted) or `ALTERNATIVE` (for example a Plus upgrade).
4. Until a row is `ACCEPTED`, every requirement it touches is `Pending approval` in [REQUIREMENTS](REQUIREMENTS.md) (REQ-PRE-003, REQ-PROMO-003, REQ-POST-001/002, REQ-DEL-001/002, REQ-ACC-003, REQ-CHK-003, REQ-CHK-005, REQ-CART-005) and work that changes delivered behaviour does not start (SOW §11).
